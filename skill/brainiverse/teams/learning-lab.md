# Learning Lab

`brainiverse team from-template learning-lab [--id <name>]`

Learns a new subject: a learning path, resources, practice, and checks of understanding.

| Agent (default names) | heroes theme | id | Role |
|---|---|---|---|
| Captain (Leader) | Captain | `leader` | Leads the learning plan and talks to the human. |
| Rachel (Mentor) | Mentor | `mentor` | Designs the learning path and explains concepts. |
| Shirin (Resource Finder) | Lumen | `researcher` | Finds the best courses, books, videos and docs. |
| Kyle (Practice Designer) | Forge | `practice-designer` | Builds exercises, projects and flashcards. |
| Sarah (Study Planner) | Atlas | `organizer` | Turns the path into a weekly schedule. |
| Parisa (Quiz Master) | Sentinel | `reviewer` | Checks understanding with quizzes and reviews answers. |

## Workflow
1. Kickoff: level, goal, time per week, preferred formats
2. Design the learning path
3. Find resources for each stage (in parallel)
4. Build practice for each stage
5. Schedule it week by week
6. Quiz and adjust as the human progresses

Works well as a **project team** in a study folder: the same crew picks up where you left off each session.
